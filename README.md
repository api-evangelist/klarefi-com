Klarefi provides an AI-powered intake platform for lending, mortgage, insurance, and legal teams. It streamlines application processes by automatically requesting missing information, verifying documents, and delivering a cited file for human decision‑making. The service aims to reduce time spent on incomplete submissions, improve data quality, and accelerate approvals across financial and legal workflows.

**Areas:** Lending · Mortgage · Insurance · Legal · AI Intake · Underwriting

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Klarefi: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
